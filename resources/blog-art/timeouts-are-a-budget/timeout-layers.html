Each box must give up before the one around it

From the outside in. Leave room at each level to fail cleanly.

User's patience ~ seconds
Load balancer / proxy 60s
App request or job 55s
Outgoing HTTP call ≤ time left − margin
inner < outer
Every timeout is shorter than the layer that is waiting on it.
If an inner one is longerThe outer layer returns an error, but the inner work keeps running. Nobody sees the result, and the user's retry runs it twice.

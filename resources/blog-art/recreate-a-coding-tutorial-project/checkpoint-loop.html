Work in checkpoints, not one long session

Each loop ends with something that runs, and a commit you can return to.

1Watch a chunk

One chapter, no typing. Note what it should do.

2Build it

Recreate just that chunk in your project.

3Run it

Confirm it works like the video.

4Commit

git commit -m "checkpoint: login works"

Repeat per chapter

A broken step costs you one chunk, not the whole project.

Fails? Fix before the next chunk

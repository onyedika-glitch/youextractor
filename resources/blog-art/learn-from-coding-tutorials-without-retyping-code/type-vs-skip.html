What to type yourself, and what to skip

Spend your typing on the idea the tutorial is teaching. Copy, clone or extract the rest.

✓Type it yourself

  • The core logic the video is about (the hook, the query, the algorithm)
  • Anything you will need to write again from scratch
  • Code you do not fully understand yet
  • Your own changes and extensions

→Copy, clone or extract

  • Project scaffolding and folder setup
  • Config files: vite.config.js, tsconfig.json
  • Package manifests and lock files
  • Styling classes and generated boilerplate

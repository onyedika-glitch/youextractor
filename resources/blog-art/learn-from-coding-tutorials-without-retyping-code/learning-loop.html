The read → run → change → recall loop

Repeat it once per section of the tutorial, not once per video.

1Read

Watch one section without typing. Note what is built and why.

2Run

Get the working code onto your machine and run it as-is.

3Change

Make one change the tutorial did not. Predict the result first.

4Recall

Close the video. Rewrite the core function from memory.

One section15–20 minutes per lap

Set up in this order

Each step depends on the one before it. Skipping ahead is where most setup errors come from.

1

Version

Match the language version used in the video

nvm use 20
›
2

Install

Install dependencies from the lock file

npm ci
›
3

.env

Copy the example and fill in your values

cp .env.example .env
›
4

Database

Start it and create an empty database

createdb myapp
›
5

Migrate

Create the tables the app expects

php artisan migrate
›
6

Run

Start it once before you change anything

npm run dev

Not every project needs every step. No database? Skip 4 and 5. No .env.example? Search the code for the settings it reads.

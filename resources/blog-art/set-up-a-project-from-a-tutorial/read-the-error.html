Read the first error, not the last

Long error output looks scary, but you only need two lines from it.

$ npm run dev
Error: Cannot find module 'dotenv'
Require stack:
- /app/src/config.js:1
- /app/src/server.js:3
at Module._resolveFilename (node:internal/...)
at Module._load (node:internal/...)
at require (node:internal/...)
code: 'MODULE_NOT_FOUND'
① The first error lineWhat went wrong: a package called dotenv is missing.
② The first line in your codeWhere it happened: line 1 of src/config.js. Skip the node_modules and internal lines.
The fix hereThe package was never installed. Run npm install dotenv, or run npm install if it is already in package.json.

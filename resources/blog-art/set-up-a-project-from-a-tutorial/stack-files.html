Which file tells you the stack

Look at the project root. The manifest file tells you what to install and with which tool.

package.json
Node · JS · TS
$ npm install
requirements.txt
Python
$ pip install -r requirements.txt
composer.json
PHP · Laravel
$ composer install
Gemfile
Ruby · Rails
$ bundle install
go.mod
Go
$ go mod download
docker-compose.yml
Docker
$ docker compose up

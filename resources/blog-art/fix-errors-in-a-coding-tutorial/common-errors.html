The 8 errors that break most tutorial projects

Symptom you see → what to try first.

1

Version mismatch

is not a function / ERESOLVE
Fix: install the versions from the video, or follow the migration guide.
2

Missing dependency

Cannot find module / ModuleNotFoundError
Fix: run the install command in the right environment.
3

Missing env variable

undefined API key / 401
Fix: copy .env.example to .env and fill in your own values.
4

Database not set up

ECONNREFUSED / no such table
Fix: start the database, then run the migrations.
5

Deprecated tool

create-react-app warnings
Fix: use the current recommended setup, keep the tutorial's code.
6

Framework conventions

404 on a page that exists
Fix: match the folder structure to your version (pages/ vs app/).
7

OS differences

'export' is not recognized
Fix: use WSL or Git Bash, or the PowerShell equivalent.
8

Off-camera fix

matches the screen, still fails
Fix: skip ahead a few minutes and check the comments.

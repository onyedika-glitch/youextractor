From tutorial to GitHub in five steps

Skipping step 3 is how API keys end up public. Do the steps in this order.

1Get the code

Clone, recreate or extract the project.

→
2Make it run

Install, set up .env, start it once.

→
3Add .gitignore

Before the first commit. Keep secrets out.

→
4Write the README

Source, run steps, your changes.

→
5Push

New repo, private first if unsure.
